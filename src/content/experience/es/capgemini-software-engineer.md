Desarrollo y evolución de aplicaciones web empresariales de alta disponibilidad y código mantenible.

### Responsabilidades clave:

- **Desarrollo FrontEnd con React y TypeScript**: Diseño e implementación de arquitecturas basadas en componentes reutilizables, custom hooks para la gestión desacoplada del estado y estándares de tipado estricto.
- **Arquitectura Hexagonal**: Aplicación de principios de diseño limpio y separación de capas (dominio, aplicación e infraestructura) para garantizar escalabilidad a largo plazo.
- **Integración de APIs REST**: Consumo, mapeo y validación de contratos de servicios externos y microservicios.
- **Testing Automatizado con Jest**: Cobertura mediante pruebas unitarias y de integración para asegurar la robustez de los módulos críticos.
- **Metodologías Ágiles (Scrum)**: Participación activa en ceremonias diarias, sprint planning, refinamientos y retrospectivas.
